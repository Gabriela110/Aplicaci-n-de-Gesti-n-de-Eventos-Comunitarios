# Aplicaci-n-de-Gesti-n-de-Eventos-Comunitarios
Aplicación de Gestión de Eventos Comunitarios - EventGo

EventGo es una aplicación móvil desarrollada con React Native y Expo que permite a los usuarios registrarse, iniciar sesión y reservar eventos comunitarios.

EventGo inicia con el registro o inicio de sesión del usuario mediante Firebase Authentication.
Una vez autenticado, el usuario accede a la pantalla principal donde puede visualizar eventos disponibles, realizar reservas y consultar sus reservas realizadas.
La navegación entre pantallas fue implementada utilizando Expo Router y las interfaces fueron desarrolladas con React Native.
